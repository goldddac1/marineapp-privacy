Website: https://goldddac1.github.io/marineapp-privacy/

Contact: golddacetup@gmail.com

Edit `index.html` to update the policy. GitHub Pages publishes directly from the root of the `main` branch. The site is static and has no JavaScript, analytics, external fonts or build dependencies.
